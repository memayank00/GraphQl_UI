# GraphQl_UI

This is a React-based UI for the GraphQl backend.

## Setup

1. Install dependencies:
   ```
   npm install
   ```

2. Start the development server:
   ```
   npm start
   ```

3. The app will run on [http://localhost:3001](http://localhost:3001) (or the port set in `.env`).

## Build for production

```
npm run build
```

## Features

- User and Admin login (separate)
- Dashboard for users and admin
- Admin can add movies (with file upload)
- Redux for state management

## Environment

- React
- Redux Toolkit
- Axios
- React Router

## API

This UI expects the backend API to be running at `http://localhost:3000`.
